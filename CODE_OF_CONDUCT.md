# Code of conduct

Be decent. Assume the other person is trying to help.

Concretely, in issues and pull requests:

- criticise the code, not the person;
- when you disagree, say what you would do instead;
- if someone bricked a board following our documentation, that is a
  documentation bug — treat it as one, not as user error;
- no harassment, no personal attacks, no dragging in unrelated fights.

Maintainers may edit, lock or delete contributions that ignore this, and may
block accounts that keep doing it.

Report a problem privately through GitHub's abuse reporting, or by opening a
private security advisory if it involves a specific person.
